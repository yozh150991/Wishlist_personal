# Набір справжніх посилань для ROADMAP 8.3 — магазини, якими користується родина.
#
# Формат: «Магазин | адреса товару», один товар у рядку; порожні рядки й рядки
# з «#» ігноруються. По 2–3 товари з кожного магазину, різних типів (одяг,
# техніка, книга, товар з варіантами розміру чи кольору).
#
# Хто читає цей файл:
#   pytest -m live              — серверний парсер (services/parser), звіт live-shops.md
#   npm run check:shops (app/)  — кнопка «У вішліст» у справжньому браузері, звіт
#                                 app/test-results/shops.md
#
# Посилання на товари — не таємниця, але не клади сюди посилань на свої
# списки, гостьові сторінки чи щось із токенами.
