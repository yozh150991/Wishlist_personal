## Редизайн інтерфейсу (вересень 2026)

Пакет від Claude Design: повне ТЗ, макети всіх екранів зі станами, три кольорові схеми й аудит контрасту. Порядок робіт — знизу вгору: спершу токени, потім каркас, далі екрани за потоком.

- [x] Токен-шар: шість палітр повним складом, `data-scheme` × `data-theme`, аудит контрасту як тест у CI (ADR-031)
- [x] Шрифти Rubik + Manrope замість Commissioner + Source Serif; Figtree із пакета відхилено — у ньому немає кирилиці
- [x] `profiles.scheme` — вибір схеми переїжджає між пристроями
- [x] Каркас: нижня навігація на телефоні, бічна на десктопі; правило «на екрані рівно один банер»
- [x] Вхід, реєстрація, скидання пароля
- [x] Списки й Список: скелети, порожньо, помилка, окремий стан «фільтр нічого не знайшов» із чипами
- [x] Мої посилання, Налаштування з блоком «Кольори»
- [x] Гостьова: власні токени, часткове бронювання кількості, лист «Вигляд», мертве посилання одним екраном
- [x] Діалоги, лічильники довжини полів, прогрес експорту
- [ ] Тост «Скасувати» на 7 секунд для зворотних дій замість підтвердження (блок G макетів)
- [ ] Прогін e2e проти локальної бази, Lighthouse, клавіатура, три мови × шість палітр
- [ ] Часовий пояс власника в терміні дії посилання: «діє до 20 грудня, 23:59 за Києвом» — потребує міграції й зміни RPC
- [ ] Код квитанції гостя (блок G): дає гостю доступ до своїх броней з іншого пристрою. Зачіпає `reservations`, потрібен окремий ADR — README пакета цієї фічі не згадує

Свідомо не реалізовано: мультивалютний підсумок «включно з 2 позиціями в EUR · курс від 17 вересня» з кадру «Список · норма». Він суперечить ADR-005 і власному README пакета («конвертації немає ніде: продукт не знає курсів і не повинен знати»).
