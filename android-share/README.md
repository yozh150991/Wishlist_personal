# Помічник «У вішліст» для Android

Маленький застосунок, що з'являється в меню «Поділитися» як **«У вішліст»**. Він відкриває сторінку товару в невидимому WebView на самому телефоні, читає назву, ціну й фото тими самими правилами, що й закладка «У вішліст», і відкриває форму `/add` у Wishlist. Так дані приходять навіть з Allegro й Amazon, які не пускають наш парсер. Рішення й межі — ADR-080, перевірка — ROADMAP 8.5а.

## Як працює

1. «Поділитися» з додатка магазину чи з Chrome → «У вішліст».
2. Внизу картка «Читаю сторінку магазину…»; сторінка вантажиться у WebView за нею.
3. Раз на секунду по сторінці проходить `assets/grab.js` (= `pageGrab` з `app/src/lib/bookmarklet.ts`).
4. Є назва, ціна й фото — відкривається форма Wishlist (у встановленому PWA, якщо він є; інакше в Chrome).
5. За 15 секунд ціни немає — помічник показує сторінку: там може бути перевірка «чи ти не робот», її можна пройти, і форма відкриється сама. Або «Додати як є».

Діагностика: `adb logcat -s WishlistShare` — кожна проба з часом і тим, що знайдено.

## Збірка

**GitHub Actions.** Кожен push, що зачіпає `android-share/`, `bookmarklet.ts` чи сам workflow, запускає `android-share`. Готовий APK — Actions → запуск → Artifacts → `wishlist-share-debug` (zip з `app-debug.apk`). Запустити вручну — «Run workflow» на сторінці workflow.

**Android Studio.** Open → тека `android-share` → Run. JDK 17, Android SDK 35.

Адреса застосунку — `wishlistOrigin` у `gradle.properties`.

## Встановлення на телефон

1. Скачати `app-debug.apk` на телефон і відкрити.
2. Дозволити встановлення з цього джерела (Chrome чи «Файли»), якщо Android спитає.
3. Play Protect може попередити про невідомого розробника — «Усе одно встановити».

Debug-APK з різних запусків CI підписано різними ключами: щоб поставити новішу збірку, спершу видали стару.

## Коли змінюється закладка

`grab.js` не редагується вручну. Після будь-якої зміни `pageGrab`:

```
cd app
npm run build:android-grab
```

і закомітити оновлений `android-share/app/src/main/assets/grab.js`. CI перевіряє, що файл збігається з `bookmarklet.ts`.
