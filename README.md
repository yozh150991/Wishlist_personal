# Wishlist_personal

[![CI](https://github.com/yozh150991/Wishlist_personal/actions/workflows/ci.yml/badge.svg)](https://github.com/yozh150991/Wishlist_personal/actions/workflows/ci.yml)

Приватні списки бажань з можливістю поділитися вибраними позиціями за секретним посиланням.

Головний список **завжди приватний**. Назовні потрапляє тільки те, що користувач свідомо вибрав і зашерив.

## Стек

| Шар | Технологія |
|---|---|
| Фронтенд | React 18 + Vite + TypeScript, власний CSS без фреймворку (шість палітр токенами), PWA (offline-first) |
| Бекенд даних | Supabase (Postgres + Auth + RLS) |
| Парсер посилань | FastAPI (Python), окремий сервіс |
| Хостинг фронту | Vercel |
| Хостинг парсера | Google Cloud Run (Docker, масштабування до нуля) |
| Фонові задачі | окремий закритий сервіс Cloud Run `wishlist-jobs` + Cloud Scheduler (ADR-048) |
| Тести | Playwright + TypeScript |

## Ключові рішення

- Автентифікація: email + пароль, з підтвердженням email.
- Спільний список — **живе посилання**: показує актуальний стан вибраних елементів.
- Гості бронюють подарунки анонімно. **Власник не бачить броней** — це навмисно.
- Ціни й картинки з посилання підтягуються через OpenGraph / schema.org.
- Мови: `uk` (за замовчуванням), `pl`, `en`.

## Швидкий старт

Перше розгортання — покроково в [docs/SETUP.md](./docs/SETUP.md).

```bash
npm install --save-dev supabase
npx supabase login
npx supabase link --project-ref <project-ref>
npx supabase db push
```

## Статус

Етапи 1–6 завершено, застосунок опубліковано:

| Що | Де |
|---|---|
| Фронтенд | `https://wishlist-personal.vercel.app` (Vercel) |
| Парсер | Google Cloud Run, регіон `europe-central2` |
| Фонові задачі | Cloud Run `wishlist-jobs` (закритий) і Cloud Scheduler — після налаштування з DEPLOY.md, розділ 9 |
| База й автентифікація | Supabase, регіон Frankfurt |
| Пошта | SMTP через Brevo |

Етап 6 завершено: застосунок встановлюється на телефон, нагадує підбити підсумки після події, вивантажує й приймає списки файлом, читається без мережі та зберігає зроблені офлайн зміни до повернення звʼязку. Див. [docs/ROADMAP.md](./docs/ROADMAP.md).

Етап 7 розпочато — дрібніше, чого бракувало проти інших вішлістів. Готове: ознаки товару (розмір, колір, модель) на картці позиції, видимі гостю (ADR-030).

**Редизайн інтерфейсу** (вересень 2026) — новий вигляд усіх екранів і **пʼять кольорових схем** × дві теми: Шавлія, Слива, Полотно, Цитрус, Ніч; Вугіль — лише з тумблера «Висока контрастність» (або системного налаштування). Схема й тема незалежні, вибір власника зберігається в профілі. Контраст перевіряється в CI — `npm run check:contrast`: 35 пар у 12 палітрах і 2820 перевірок разом з оформленнями. Деталі — ADR-031, ADR-033 і [docs/ROADMAP.md](./docs/ROADMAP.md).

**Оновлення дизайну від 28 вересня** (пакет, файли 08–10): оформлення списку за подією — гість бачить список у відтінку події (ADR-034); гість без акаунта з ключем в особистому посиланні `/s/…/g/…` і кодом із пʼяти символів, позначки на рівні списку, сліпе скидання власником (ADR-035); розділи й ручний порядок, який бачить гість, і фільтри гостя «Вільні · Усі» (ADR-036); термін посилання в часовому поясі власника (ADR-037); закрито побічні канали, якими власник міг би вирахувати позначки (ADR-038). e2e проти локальної бази — 262 зелених у двох розкладках, 2 пропущено без парсера; pgTAP — 173 перевірки у восьми файлах. Лишилась ручна перевірка — Lighthouse, клавіатура, три мови очима.

**Дизайн v2** (пакет потоків 2.0) росте поруч із v1 на тих самих даних; вмикається в Налаштуваннях або `?design=v2` (ADR-032, ADR-039). Готові вхід і реєстрація паролем без кодів із пошти (ADR-042) та всі екрани власника: «Мої списки», сторінка списку з «Поділитися», порядком і оформленням, «Мої посилання» й «Налаштування». Із нових функцій готові «Після події» й архів (ADR-045), чернетки й «Поділитися» з інших застосунків (ADR-046), щорічні свята з нагадуванням за місяць (ADR-047), щоденна перевірка посилань — «Сторінки немає», «Немає в наявності», «Ціна змінилась» — в окремому закритому сервісі (ADR-048). Далі — сповіщення, потім гостьова v2 на `/l/…` (ROADMAP, «Дизайн v2»).

Застосовані міграції з цього моменту не редагуються — лише нові файли: база одна, і вона бойова.
